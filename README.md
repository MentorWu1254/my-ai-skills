# my-ai-skills

GitHub 入門練習：記錄 AI skills、提示詞與版本管理操作。

## 這是什麼

這是一個練習用專案，用來學習 GitHub 的檔案管理、版本紀錄與協作流程，並逐步整理 AI skills 與提示詞範例。

## 怎麼使用

1. 先閱讀 README，了解專案用途。
2. 開啟 [整理文章重點範例](skills/my-skill/SKILL.md)，查看 skill 的名稱、適用時機與操作步驟。
3. 修改後用 commit 保存版本，並寫清楚改了什麼；需要討論的修改可透過 Pull request 提出。

這個範例目前保存在 GitHub，尚未安裝到 AI 工具。

## 協作練習流程

1. 從 `main` 建立分支，在分支上修改檔案。
2. 提交 commit，再建立 Pull request。
3. 檢查 Files changed，確認內容後合併回 `main`。
4. 到 History 查看修改紀錄與舊版本。
